# Unplugged Silicon: code

Code from the [Unplugged Silicon](https://www.youtube.com/@unpluggedsilicon) videos: free, offline, private AI on your Mac,
and how it actually works. Every model gets two videos, a step-by-step setup and a layer-by-layer deep dive.
The written guides are on the blog: https://unpluggedsilicon.blogspot.com

| Folder | Model | Videos |
|---|---|---|
| [ep02-whisper](ep02-whisper) | Whisper large-v3-turbo (speech-to-text) | Free Speech-to-Text on Your Mac · How Whisper Actually Works |
| [ep03-llm](ep03-llm) | Qwen3.5-4B (AI chat, MLX) | Run a Free AI Chatbot on Your Mac · How an LLM Actually Works |
| [ep04-flux](ep04-flux) | FLUX.2 Klein 4B (image generation, mflux) | Run FLUX Locally · How AI Image Generators Actually Work |

Everything here was run on an Apple silicon Mac (M4, 16 GB) with the internet switched off after the one-time model
download. Every number in the videos comes from those runs.
