Unplugged Silicon

Privacy policy

Last updated: 28 November 2026

This policy covers Unplugged Publish, the publishing tool of the Unplugged Silicon channel, and this website.

Who uses the app

Unplugged Publish is used only by the owner of the Unplugged Silicon channel, to manage the channel's own YouTube videos and Blogger blog. It is not offered to the public.

What data the app accesses

When the channel owner signs in with Google, the app asks for:

  • YouTube (youtube.force-ssl): to read the channel's own uploads and update their title, description, tags, thumbnail and captions, and to post a comment on the channel's own videos.
  • Blogger (blogger): to create and update posts and pages on the channel's own blog.

The app does not read, collect or store data about viewers, commenters or any other Google user.

How the data is stored

The sign-in token is saved only on the channel owner's computer, in a file readable only by that user. No data is sent to any server other than Google's own APIs. Nothing is sold, shared with third parties or used for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

Unplugged Publish uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's Privacy Policy applies.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file removes all stored data.

This website

This site is hosted on GitHub Pages. It sets no cookies and runs no analytics. GitHub may log visits as described in the GitHub Privacy Statement.

Contact

Questions: open an issue at github.com/unpluggedsilicon/code or use the contact details on the YouTube channel.
